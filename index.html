LDraw 3D Web
Viewer & Editor

A modern web-based viewer and editor for LDraw models. Built with TypeScript, React, Three.js, and Monaco Editor. View, edit, and manipulate LEGO models in 3D directly in your browser.

View on GitHub NPM Package
Quick Start
# Run directly with npx
$ npx ldraw-core-viewer

# Or install globally
$ npm install -g ldraw-core-viewer
Capabilities

Built for Builders

Everything you need to view, edit, and create LDraw models in the browser.

◎

Real-Time 3D Visualization

Render LDraw models instantly using WebGL for a smooth, interactive experience with full camera controls.

⌨

Live Code Editing

Integrated Monaco Editor (VS Code's engine) with syntax highlighting for live LDraw code changes.

⊞

Interactive Manipulation

Select, multi-select, move, and rotate objects in the 3D scene with intuitive transform controls.

⬢

Parts Library Integration

Automatically resolves and loads standard LDraw part references to correctly build any model.

◫

Full File Management

Create new files, load existing models, and save changes back to the server seamlessly.

⚡

Modern Architecture

Built with React, TypeScript, Three.js, and Zustand for a maintainable, type-safe codebase.

The Journey

The History of LDraw

1995

A Universal Standard is Born

James Jessiman created LDraw, an open file format defining a universal coordinate system for all digital bricks.

1997

Community Governance

After Jessiman's passing, a global fan community formed LDraw.org to maintain and expand the digital parts library.

2000s

First Generation Tools

C++ desktop editors like MLCad and LeoCAD introduced step-based instruction building, mirroring real LEGO manuals.

Today

The Web Era

This project brings LDraw into modern browsers—accessible to anyone, anywhere, without installation.
